



# **Abstract**

将大语言模型 (LLMs) 融入人机交互领域，为机器人在复杂环境中理解并执行自然语言指令开辟了新途径。本研究探索在模拟医疗场景中应用LLMs解读用户指令并验证其执行效果。我们首先设计测试框架，评估LLM将自然语言指令转化为结构化命令的能力。随后，我们构建医疗场景模拟环境以评估命令执行的准确性与可靠性。实验结果表明，尽管LLM在理解情景指令方面展现出潜力，但在处理歧义性。确保稳定性及适应性领域特定需求方面仍然存在挑战。研究发现既揭示了LLM驱动方法在未来医疗HRI应用中的潜力，也指出了其局限性，为通过优化提示设计，错误分析和领域适应性提升准确性与鲁棒性提供了启示。

近年来，自然语言处理（NLP）与机器人技术的融合为推进人机交互（HRI）开辟了新路径。传统基于规则的系统常因僵化的沟通模式和有限的适应性而难以提供理想的交互体验。以OpenAI的ChatGPT为代表的大型语言模型（LLM）的迅猛发展，显著改变了这一局面。与早期方法不同，LLM展现出具备上下文感知能力、连贯且类人化的对话能力，不仅能实现响应式对话，还能进行结构化逻辑推理。这些进步凸显了LLM作为增强机器人控制与通信的强大机制，弥合了人类认知过程与机器人执行之间的鸿沟。基于此基础，本研究构建了医疗辅助机器人仿真环境，其中基于LLM的对话系统支持复杂情境驱动的任务执行。研究成果表明，将认知机器人技术与LLM驱动对话相结合，可显著提升辅助场景中的适应性、自然度和有效性，为智能直观的人机协作开辟了全新范式


大型语言模型（LLM）的最新进展，以ChatGPT为代表，标志着对话模式从僵化的规则驱动型向类人化、情境感知型及推理驱动型交互的范式转变。这一发展为提升人机交互（HRI）提供了新机遇，尤其在医疗保健等需要直观精准沟通的领域。本研究探索将基于LLM的指令理解管道与人形机器人集成，以实现自然语言命令的解读与执行。通过结合文本转命令翻译模块与Talk2Car数据集，并在Gazebo医疗模拟环境中部署生成的指令，我们证明机器人能够更有效地执行复杂且语境丰富的指令。研究成果揭示了LLM驱动的交互界面如何弥合自然沟通与机器人动作的鸿沟，为医疗及其他领域构建更便捷、灵活且可信赖的人机交互开辟了前景广阔的道路。
