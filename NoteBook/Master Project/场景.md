


| 場景編號 | 使用者語音輸入    | 預期機器人行為       | 模擬方式說明                  |
| ---- | ---------- | ------------- | ----------------------- |
| ①    | “請幫我拿藥”    | 導航至藥櫃，返回使用者旁邊 | 使用 `nav2` + Python 指令控制 |
| ②    | “我需要幫忙”    | 導航至使用者並發出提示音  | ROS topic 轉為動作命令        |

| ④    | “我今天有吃藥嗎？” | 根據記錄回答有/沒有    | 整合記憶模組（儲存交互紀錄）          |
